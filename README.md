# 輪読事前課題 集計スクリプト

清水たくみ研「輪読事前課題提出フォーム（回答）」スプレッドシート用の Apps Script。手動実行専用。

## 導入

1. スプレッドシートで「拡張機能 > Apps Script」を開き、`Code.gs` の中身を貼って保存する
2. スプレッドシートを再読み込みすると、メニューに「輪読集計」が出る
3. 初回だけ承認ダイアログが出るので許可する
4. 「ファイル > 設定」のタイムゾーンが「(GMT+09:00) 東京」になっていることを確認する

## メニュー

| 項目 | すること |
| --- | --- |
| 提出状況を更新 | `フォームの回答 1` を読み、`集計` の各セルを ◯ / 遅延 / 未 にする |
| 名簿と発表者を反映 | `輪読スケジュール` の発表者を `集計` に「発表」として入れる。名簿にいない人は末尾に行を足す |

どちらも最後にダイアログが出て、警告があれば一覧で表示する。

## 判定ルール

- 期限は研究会の日付（`集計` 1行目）の前日 18:00 JST。18:00:00 ちょうどは期限内
- 同じ人・同じ回の提出が複数あるときは、最初の提出で判定する
- 「発表」のセルは書き換えない
- ◯ / 遅延 / 未 / 発表 / 空 以外の値（「欠席」など）は残して、警告に出す
- 名前は全角/半角をそろえ（NFKC）、空白を除いてから照合する
- 輪読回はフォームの「輪読回」の値の先頭（`10/13 …` の `10/13`）を `集計` 見出しの月日と照合する

警告に出るもの: 名簿にない名前、輪読回が空・読めない・見出しにない回答、想定外の値、名簿の重複、見出し日付の逆順（年の入れ間違い）。

## 来学期の使い方

1. `集計` の 1行目に研究会の日付を左から順に入れる（年まで正しく）。名簿は A2 から空白なしで並べる
2. `輪読スケジュール` を A列: 日付、B列以降: 発表者 で書き換える
3. フォームの「輪読回」の選択肢を `M/D タイトル` の形で作る（設問タイトルは「輪読回」のまま）
4. 「名簿と発表者を反映」→「提出状況を更新」

回数を増やして I 列より右に広げた場合は、J〜O 列の式（`$B2:$I2`）を手で広げる。人数はスクリプトで追加すれば式の範囲も自動で広がる（30〜33行目の式は空行の 29 行目まで含めてある）。

設定（シート名・見出し名・期限）は `Code.gs` 冒頭の `CONFIG` にまとめてある。
