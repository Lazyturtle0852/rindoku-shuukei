輪読集計スクリプト

輪読事前課題フォームの提出状況を、スプレッドシートのメニューから一回で集計する

Google フォームの回答がたまる フォームの回答 1 シートを読み、集計 シートの「人 × 輪読回」のマスを ◯ 遅延 未 - で埋めます。自動では動かず、押したときだけ集計します。

メニュー

スプレッドシートを開くと、上部に「輪読集計」メニューが出ます。

提出状況を更新

フォームの回答を読み、各マスを ◯ / 遅延 / 未 / - にする。毎週使うのはこれ。

名簿と発表者を反映

輪読スケジュール の発表者のマスを「発表」にする。名簿にいない人は末尾に行を足す。学期はじめに一度。

どちらも最後にダイアログが出て、気になる点があれば警告として一覧で表示します。

判定のしかた

期限は研究会の前日 18:00（日本時間）です。研究会の日付は 集計 の1行目の見出しから読みます。

受付 10/12 18:00 期限 10/13 研究会
この間に最初の提出 → ◯期限後 → 遅延
結果条件
◯期限までに提出がある（18:00:00 ちょうどは期限内）
遅延提出はあるが、最初の提出が期限を過ぎている
未期限を過ぎても提出がない
-まだ期限前で、提出もない（期限前に出していれば ◯）
発表その回の発表者。提出不要なので、スクリプトは書き換えない

細かいルール

  • どの回の提出かは、フォームの「輪読回」の先頭の日付で決めます。10/13 チームインテリジェンス：序章＋第1部 なら 10/13 の回です。
  • 同じ人が同じ回に何度か出したときは、最初の提出で判定します。期限内に出したあとで修正版を送っても ◯ のままです。
  • 名前は全角/半角の違いと空白を無視して名簿と照合します（漆原　裕士 と 漆原裕士 は同じ人）。
  • 名簿は 集計 の A2 から下へ、空白セルまで。輪読回は B1 から右へ、日付が続くところまで。人数や回数が変わっても自動で追従します。
実行するたびに全部計算し直すので、提出のないマスに手で ◯ を入れても次の実行で「未」か「-」に戻ります。残したい例外は「免除」「欠席」のように別の言葉で書いてください。そのマスはそのまま残り、警告に出ます。

警告に出るもの

次のものは集計に入れず、実行の最後に一覧で知らせます。

警告よくある原因と直し方
名前が名簿にないフォームでの名前の書き間違い、名簿への追加漏れ。名簿の表記に合わせて回答シートの名前を直す
輪読回が読めない・見出しにない回答の「輪読回」が空、または集計の見出しにない日付
想定外の値を残したマスに ◯ / 遅延 / 未 / - / 発表 以外が入っている。意図したものならそのままでよい
名簿の重複同じ人が A 列に二度いる
見出しの日付が前の回より前年の入れ間違い（1月の回が前年になっているなど）。期限の判定がずれるので直す

導入

  1. 集計用のスプレッドシートで「拡張機能 › Apps Script」を開く
  2. 最初からある コード.gs の中身を消し、下のコードを貼って保存する
  3. スプレッドシートを再読み込みすると、メニューに「輪読集計」が出る
  4. 初回だけ承認を求められるので許可する
  5. 「ファイル › 設定」のタイムゾーンが「(GMT+09:00) 東京」になっているか確かめる
読み込み中…（読み込めない場合は Code.gs を直接開いてください）

必要なシート

シート中身
フォームの回答 1フォームとつながった回答シート。見出しに「タイムスタンプ」「名前」「輪読回」が必要
集計A1「氏名」、B1 から右に研究会の日付、A2 から下に名簿
輪読スケジュールA 列に研究会の日付、B 列以降にその回の発表者

来学期に使い回すとき

  1. 集計 の1行目に研究会の日付を左から順に入れる。年まで正しく入れる
  2. 輪読スケジュール を新しい発表者で書き換える
  3. フォームの「輪読回」の選択肢を M/D タイトル の形で作り直す。設問タイトルは「輪読回」のまま
  4. 「名簿と発表者を反映」で名簿と「発表」を入れ、あとは毎週「提出状況を更新」

シート名・見出し名・期限（前日 18:00）は Code.gs 冒頭の CONFIG で変えられます。デモで「今」を固定したいときは CONFIG.NOW に '2026-11-09T12:00:00+09:00' のように書きます（普段は null）。輪読回を I 列より右に増やしたときは、J〜O 列の集計式の範囲（$B2:$I2）を手で広げてください。
